NFT คือโทเคนบนบล็อกเชนที่ชี้ไปยังไฟล์สื่อชิ้นหนึ่ง และบอกว่าใครเป็นเจ้าของ NFT ส่วนใหญ่ไม่ได้บอกอะไรเกี่ยวกับโลกนอกเชนเลย แต่ geo-NFT บอก: มันบันทึกว่าถูกสร้างที่ไหน และเมื่อไร

นั่นคือแนวคิดทั้งหมดของ Beenzer รูปที่ถ่ายริมทะเลสาบไม่ใช่แค่ภาพหนึ่งภาพ แต่เป็นภาพของสถานที่ _นั้น_ ในช่วงเวลา _นั้น_ เมื่อคุณมินต์โพสต์ Beenzer จะเขียนทั้งสองอย่างลงในเมทาดาทาของโทเคน

## มีอะไรอยู่ใน Beenzer หนึ่งชิ้น

การมินต์แต่ละครั้งจะอัปโหลดมีเดียไปที่ Arweave แล้วตามด้วยไฟล์เมทาดาทาที่อยู่คู่กัน ซึ่งมีแอตทริบิวต์เหล่านี้:

| แอตทริบิวต์       | สิ่งที่เก็บไว้                                      |
| ----------------- | --------------------------------------------------- |
| `CREATOR`         | วอลเล็ตที่โพสต์                                     |
| `USERNAME`        | ชื่อผู้ใช้ Beenzer ของผู้สร้าง                      |
| `TYPE`            | ประเภทมีเดีย: รูปภาพ วิดีโอ หรือเสียง               |
| `SUPPLY`          | จำนวนเอดิชันสูงสุดที่จะมีได้                        |
| `FLOOR`           | ราคาของหนึ่งเอดิชัน                                 |
| `DATE`, `TIME UTC`| เวลาที่มินต์                                        |
| `CITY`            | เมืองที่โพสต์                                       |
| `LATITUDE`, `LONGITUDE` | จุดบนแผนที่                                   |
| `VISIBILITY`      | ระยะไกลแค่ไหนที่ยังเจอได้ หรือทั่วโลก               |
| `MAX LAT` … `MIN LON` | รัศมีนั้นในรูปกรอบบนแผนที่                     |

## ตัวอย่างจริง

นี่คือ BEENZER #18 ที่ @vincent มินต์เมื่อวันที่ 16 กุมภาพันธ์ 2023 ด้านล่างคือแอตทริบิวต์ตามที่อยู่บน Arweave โดยในที่นี้ปัดพิกัดให้หยาบลงเหลือประมาณหนึ่งกิโลเมตร ซึ่งเท่ากับรัศมีการมองเห็นของโพสต์นี้เอง:

```json
{
  "name": "BEENZER #18",
  "description": "🤘",
  "symbol": "BEENZER",
  "attributes": [
    { "trait_type": "USERNAME", "value": "vincent" },
    { "trait_type": "TYPE", "value": "image/png" },
    { "trait_type": "SUPPLY", "value": "1" },
    { "trait_type": "FLOOR", "value": "0.1 SOL" },
    { "trait_type": "DATE", "value": "2023-02-16" },
    { "trait_type": "TIME UTC", "value": "13:41:43" },
    { "trait_type": "CITY", "value": "Savigny" },
    { "trait_type": "LATITUDE", "value": "46.54…" },
    { "trait_type": "LONGITUDE", "value": "6.72…" },
    { "trait_type": "VISIBILITY", "value": "1 km" }
  ]
}
```

คุณตรวจสอบโทเคนนี้ด้วยตัวเองได้ [บน Solscan](https://solscan.io/token/BXzXwJVhqQerunAWnjnXPyhtXG4SGrMQWtstp8rshKFZ)

## ทำไมกรอบนี้ถึงสำคัญ

รัศมีการมองเห็นไม่ได้มีไว้ประดับ เมื่อคุณเปิดแผนที่ Beenzer จะแสดงโพสต์ที่กรอบการมองเห็นครอบคลุมตำแหน่งที่คุณอยู่ รวมถึงโพสต์ที่ตั้งให้เห็นได้ทั่วโลก โพสต์ที่มีรัศมี 1 กม. คือสิ่งที่คุณจะเจอได้ก็ต่อเมื่อไปอยู่ที่นั่น ส่วนโพสต์แบบทั่วโลก ใครก็เห็นได้

ดังนั้น geo-NFT จึงเป็นสองอย่างในเวลาเดียวกัน: บันทึกของสถานที่หนึ่ง และวิธีฝากบางสิ่งไว้ในสถานที่นั้นให้คนที่ผ่านไปมา

## การมินต์มีค่าใช้จ่ายเท่าไร

การมินต์จะเปลี่ยนโพสต์ให้เป็นโทเคนที่คุณถือไว้ในวอลเล็ต พร้อมเอดิชันที่คนอื่นสะสมได้ โดยมีค่ามินต์เป็น SOL และแอปจะแสดงค่านี้ รวมถึงปลายทางของเงิน ก่อนที่คุณจะอนุมัติอะไรใน Phantom
