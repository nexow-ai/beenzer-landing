NFT — это токен в блокчейне, который указывает на медиафайл и сообщает, кто им владеет. Большинство NFT ничего не говорят о мире за пределами блокчейна. Гео-NFT говорит: он фиксирует, где и когда был создан.

В этом вся идея Beenzer. Фото, сделанное на берегу озера, — не просто снимок; это снимок _того самого_ места в _тот самый_ момент. Когда вы выпускаете пост как NFT, Beenzer записывает и то и другое в метаданные токена.

## Что входит в Beenzer

При каждом выпуске медиафайл загружается в Arweave, а рядом с ним — файл метаданных с такими атрибутами:

| Атрибут           | Что в нём хранится                                  |
| ----------------- | --------------------------------------------------- |
| `CREATOR`         | Кошелёк, с которого опубликован пост                |
| `USERNAME`        | Имя пользователя автора в Beenzer                   |
| `TYPE`            | Тип медиа: изображение, видео или звук              |
| `SUPPLY`          | Сколько экземпляров может когда-либо существовать   |
| `FLOOR`           | Цена одного экземпляра                              |
| `DATE`, `TIME UTC`| Когда он был выпущен                                |
| `CITY`            | Город, из которого опубликован пост                 |
| `LATITUDE`, `LONGITUDE` | Точка на карте                                |
| `VISIBILITY`      | На каком расстоянии его можно найти — или по всему миру |
| `MAX LAT` … `MIN LON` | Этот радиус в виде прямоугольника на карте      |

## Настоящий пример

Вот BEENZER #18, выпущенный @vincent 16 февраля 2023 года. Это его атрибуты в том виде, в каком они хранятся на Arweave; координаты здесь округлены примерно до километра — это собственный радиус видимости поста:

```json
{
  "name": "BEENZER #18",
  "description": "🤘",
  "symbol": "BEENZER",
  "attributes": [
    { "trait_type": "USERNAME", "value": "vincent" },
    { "trait_type": "TYPE", "value": "image/png" },
    { "trait_type": "SUPPLY", "value": "1" },
    { "trait_type": "FLOOR", "value": "0.1 SOL" },
    { "trait_type": "DATE", "value": "2023-02-16" },
    { "trait_type": "TIME UTC", "value": "13:41:43" },
    { "trait_type": "CITY", "value": "Savigny" },
    { "trait_type": "LATITUDE", "value": "46.54…" },
    { "trait_type": "LONGITUDE", "value": "6.72…" },
    { "trait_type": "VISIBILITY", "value": "1 km" }

}
```

Вы можете сами проверить токен [на Solscan](https://solscan.io/token/BXzXwJVhqQerunAWnjnXPyhtXG4SGrMQWtstp8rshKFZ).

## Зачем нужен прямоугольник

Радиус видимости — не украшение. Когда вы открываете карту, Beenzer показывает посты, в прямоугольник видимости которых попадает ваше местоположение, а также посты, видимые по всему миру. Пост с радиусом 1 км находят, оказавшись на месте. Пост для всего мира может увидеть кто угодно.

Получается, гео-NFT — это сразу две вещи: запись о месте и способ оставить что-то в этом месте для тех, кто будет проходить мимо.

## Сколько стоит выпуск

Выпуск превращает пост в токен, который хранится в вашем кошельке, с экземплярами, которые могут собирать другие. За него берётся комиссия в SOL, и приложение показывает её и то, куда она уходит, до того как вы что-либо подтвердите в Phantom.
