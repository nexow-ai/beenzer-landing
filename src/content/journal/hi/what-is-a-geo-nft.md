NFT ब्लॉकचेन पर एक टोकन है, जो किसी मीडिया की ओर इशारा करता है और बताता है कि उसका मालिक कौन है। ज़्यादातर NFT चेन के बाहर की दुनिया के बारे में कुछ नहीं बताते। जियो-NFT बताता है: वह दर्ज करता है कि वह कहाँ बना, और कब।

Beenzer के पीछे पूरा आइडिया यही है। झील के किनारे ली गई फ़ोटो सिर्फ़ एक तस्वीर नहीं है; वह _उस_ जगह की, _उस_ पल की तस्वीर है। जब आप कोई पोस्ट मिंट करते हैं, तो Beenzer ये दोनों बातें टोकन के मेटाडेटा में लिख देता है।

## एक Beenzer में क्या-क्या होता है

हर मिंट पहले मीडिया को Arweave पर अपलोड करता है, फिर उसके साथ एक मेटाडेटा फ़ाइल, जिसमें ये एट्रिब्यूट होते हैं:

| एट्रिब्यूट        | इसमें क्या होता है                                  |
| ----------------- | --------------------------------------------------- |
| `CREATOR`         | वह वॉलेट जिसने इसे पोस्ट किया                       |
| `USERNAME`        | क्रिएटर का Beenzer यूज़रनेम                         |
| `TYPE`            | मीडिया का प्रकार: इमेज, वीडियो या आवाज़              |
| `SUPPLY`          | ज़्यादा से ज़्यादा कितने एडिशन हो सकते हैं          |
| `FLOOR`           | एक एडिशन की कीमत                                    |
| `DATE`, `TIME UTC`| यह कब मिंट हुआ                                      |
| `CITY`            | वह शहर जहाँ से इसे पोस्ट किया गया                   |
| `LATITUDE`, `LONGITUDE` | मैप पर वह बिंदु                               |
| `VISIBILITY`      | इसे कितनी दूर से ढूँढा जा सकता है, या दुनिया भर से  |
| `MAX LAT` … `MIN LON` | वही दायरा, मैप पर एक बॉक्स के रूप में          |

## एक असली उदाहरण

यह है BEENZER #18, जिसे @vincent ने 16 फ़रवरी 2023 को मिंट किया। ये इसके एट्रिब्यूट हैं, ठीक वैसे जैसे वे Arweave पर दर्ज हैं; बस यहाँ निर्देशांकों को लगभग एक किलोमीटर तक राउंड किया गया है, जो इस पोस्ट का अपना दिखने का दायरा है:

```json
{
  "name": "BEENZER #18",
  "description": "🤘",
  "symbol": "BEENZER",
  "attributes": [
    { "trait_type": "USERNAME", "value": "vincent" },
    { "trait_type": "TYPE", "value": "image/png" },
    { "trait_type": "SUPPLY", "value": "1" },
    { "trait_type": "FLOOR", "value": "0.1 SOL" },
    { "trait_type": "DATE", "value": "2023-02-16" },
    { "trait_type": "TIME UTC", "value": "13:41:43" },
    { "trait_type": "CITY", "value": "Savigny" },
    { "trait_type": "LATITUDE", "value": "46.54…" },
    { "trait_type": "LONGITUDE", "value": "6.72…" },
    { "trait_type": "VISIBILITY", "value": "1 km" }
  ]
}
```

आप इस टोकन को ख़ुद [Solscan पर](https://solscan.io/token/BXzXwJVhqQerunAWnjnXPyhtXG4SGrMQWtstp8rshKFZ) जाँच सकते हैं।

## बॉक्स क्यों मायने रखता है

दिखने का दायरा सिर्फ़ सजावट नहीं है। जब आप मैप खोलते हैं, तो Beenzer आपको वे पोस्ट दिखाता है जिनके विज़िबिलिटी बॉक्स में आपकी मौजूदा जगह आती है, साथ ही वे पोस्ट भी जो दुनिया भर के लिए सेट हैं। 1 किमी दायरे वाली पोस्ट ऐसी चीज़ है जिसे आप वहाँ पहुँचकर ही ढूँढ पाते हैं। दुनिया भर वाली पोस्ट कोई भी देख सकता है।

तो जियो-NFT एक साथ दो चीज़ें है: किसी जगह का रिकॉर्ड, और किसी जगह पर कुछ छोड़ जाने का तरीका, उन लोगों के लिए जो वहाँ से गुज़रते हैं।

## मिंट करने में कितना खर्च आता है

मिंट करने से एक पोस्ट ऐसे टोकन में बदल जाती है जो आपके वॉलेट में रहता है, और जिसके एडिशन दूसरे लोग कलेक्ट कर सकते हैं। इसके लिए SOL में एक मिंट फ़ीस लगती है, और Phantom में कुछ भी मंज़ूर करने से पहले ऐप आपको वह फ़ीस दिखाता है, और यह भी कि वह कहाँ जाती है।
