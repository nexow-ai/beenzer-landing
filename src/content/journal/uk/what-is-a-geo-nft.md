NFT — це токен у блокчейні, який вказує на медіафайл і повідомляє, хто ним володіє. Більшість NFT нічого не кажуть про світ поза блокчейном. Гео-NFT каже: він фіксує, де і коли його створено.

У цьому вся ідея Beenzer. Фото, зроблене на березі озера, — не просто знімок; це знімок _саме того_ місця в _саме ту_ мить. Коли ви випускаєте допис як NFT, Beenzer записує і те, і інше в метадані токена.

## Що потрапляє в Beenzer

Під час кожного випуску медіафайл завантажується в Arweave, а поруч із ним — файл метаданих із такими атрибутами:

| Атрибут           | Що в ньому зберігається                             |
| ----------------- | --------------------------------------------------- |
| `CREATOR`         | Гаманець, з якого опубліковано допис                |
| `USERNAME`        | Ім’я користувача автора в Beenzer                   |
| `TYPE`            | Тип медіа: зображення, відео чи звук                |
| `SUPPLY`          | Скільки примірників може будь-коли існувати         |
| `FLOOR`           | Ціна одного примірника                              |
| `DATE`, `TIME UTC`| Коли його випущено                                  |
| `CITY`            | Місто, з якого опубліковано допис                   |
| `LATITUDE`, `LONGITUDE` | Точка на мапі                                 |
| `VISIBILITY`      | На якій відстані його можна знайти — або на весь світ |
| `MAX LAT` … `MIN LON` | Цей радіус у вигляді прямокутника на мапі       |

## Справжній приклад

Ось BEENZER #18, випущений @vincent 16 лютого 2023 року. Це його атрибути в тому вигляді, у якому вони зберігаються в Arweave; координати тут округлено приблизно до кілометра — це власний радіус видимості допису:

```json
{
  "name": "BEENZER #18",
  "description": "🤘",
  "symbol": "BEENZER",
  "attributes": [
    { "trait_type": "USERNAME", "value": "vincent" },
    { "trait_type": "TYPE", "value": "image/png" },
    { "trait_type": "SUPPLY", "value": "1" },
    { "trait_type": "FLOOR", "value": "0.1 SOL" },
    { "trait_type": "DATE", "value": "2023-02-16" },
    { "trait_type": "TIME UTC", "value": "13:41:43" },
    { "trait_type": "CITY", "value": "Savigny" },
    { "trait_type": "LATITUDE", "value": "46.54…" },
    { "trait_type": "LONGITUDE", "value": "6.72…" },
    { "trait_type": "VISIBILITY", "value": "1 km" }
  ]
}
```

Ви можете самі перевірити токен [на Solscan](https://solscan.io/token/BXzXwJVhqQerunAWnjnXPyhtXG4SGrMQWtstp8rshKFZ).

## Навіщо потрібен прямокутник

Радіус видимості — не прикраса. Коли ви відкриваєте мапу, Beenzer показує дописи, у прямокутник видимості яких потрапляє ваше місцеперебування, а також ті, що видимі на весь світ. Допис із радіусом 1 км знаходять, опинившись на місці. Допис для всього світу може побачити будь-хто.

Тож гео-NFT — це водночас дві речі: запис про місце і спосіб залишити щось у цьому місці для тих, хто проходитиме повз.

## Скільки коштує випуск

Випуск перетворює допис на токен, який зберігається у вашому гаманці, з примірниками, які можуть колекціонувати інші. За нього стягується комісія в SOL, і застосунок показує її, а також те, куди вона йде, ще до того, як ви щось підтвердите в Phantom.
