الـ NFT رمزٌ على بلوكتشين يشير إلى قطعة من الوسائط ويبيّن من يملكها. ومعظم رموز NFT لا تقول شيئًا عن العالم خارج السلسلة. أما الـ NFT الجغرافي فيقول: إنه يسجّل أين صُنع، ومتى.

وهذه هي الفكرة كلها وراء Beenzer. الصورة الملتقطة على ضفة بحيرة ليست مجرد صورة؛ إنها صورة _ذلك_ المكان في _تلك_ اللحظة. وحين تسكّ منشورًا، يكتب Beenzer الاثنين في البيانات الوصفية للرمز.

## ماذا يحتوي كل Beenzer

كل عملية سكّ ترفع الوسائط إلى Arweave، ثم ملف بيانات وصفية بجانبها، بهذه السمات:

| السمة | ما تحتويه |
| ----- | --------- |
| `CREATOR` | المحفظة التي نشرته |
| `USERNAME` | اسم مستخدم المُنشئ في Beenzer |
| `TYPE` | نوع الوسائط: صورة أو فيديو أو صوت |
| `SUPPLY` | عدد النسخ التي يمكن أن توجد على الإطلاق |
| `FLOOR` | سعر النسخة الواحدة |
| `DATE`، `TIME UTC` | متى سُكّ |
| `CITY` | المدينة التي نُشر منها |
| `LATITUDE`، `LONGITUDE` | النقطة على الخريطة |
| `VISIBILITY` | من أي مسافة يمكن العثور عليه، أو للعالم كله |
| `MAX LAT` … `MIN LON` | ذلك النطاق، كمربّع على الخريطة |

## مثال حقيقي

إليك BEENZER #18، الذي سكّه &lrm;@vincent يوم 16 فبراير 2023. هذه سماته كما هي محفوظة على Arweave، مع تقريب الإحداثيات هنا إلى نحو كيلومتر، وهو نطاق ظهور المنشور نفسه:

```json
{
  "name": "BEENZER #18",
  "description": "🤘",
  "symbol": "BEENZER",
  "attributes": [
    { "trait_type": "USERNAME", "value": "vincent" },
    { "trait_type": "TYPE", "value": "image/png" },
    { "trait_type": "SUPPLY", "value": "1" },
    { "trait_type": "FLOOR", "value": "0.1 SOL" },
    { "trait_type": "DATE", "value": "2023-02-16" },
    { "trait_type": "TIME UTC", "value": "13:41:43" },
    { "trait_type": "CITY", "value": "Savigny" },
    { "trait_type": "LATITUDE", "value": "46.54…" },
    { "trait_type": "LONGITUDE", "value": "6.72…" },
    { "trait_type": "VISIBILITY", "value": "1 km" }
  ]
}
```

يمكنك التحقق من الرمز بنفسك [على Solscan](https://solscan.io/token/BXzXwJVhqQerunAWnjnXPyhtXG4SGrMQWtstp8rshKFZ).

## لماذا يهمّ المربّع

نطاق الظهور ليس للزينة. حين تفتح الخريطة، يعرض لك Beenzer المنشورات التي يضم مربّع ظهورها موقعك، إضافةً إلى المنشورات المضبوطة على الظهور للعالم كله. المنشور ذو النطاق البالغ 1 كم شيءٌ تجده حين تكون هناك. أما المنشور العالمي، فيمكن لأي أحد أن يراه.

إذن، الـ NFT الجغرافي شيئان في آن واحد: سجلٌّ لمكان، وطريقة لترك شيء في مكان لمن يمرّ به.

## كم يكلّف السكّ

السكّ يحوّل المنشور إلى رمز تحتفظ به في محفظتك، بنسخ يمكن للآخرين جمعها. وتكلفته رسوم سكّ بعملة SOL، ويعرضها التطبيق، ويعرض وجهتها، قبل أن توافق على أي شيء في Phantom.
